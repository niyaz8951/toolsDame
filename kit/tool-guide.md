# How to make a tool (for space admins and tool managers)

1. **New tool.** In your space press New tool. Give it a name, a short id, an icon and a colour. Choose who may open it.
2. **Get the files.** Press AI prompt, copy it, add what the tool should do in your own words, and give it to the approved AI. No real data into the AI.
3. **Upload.** Open the tool's Files page and drop the files (or a zip) there. The site checks them and tells you in plain words what to fix.
4. **Tables.** If the tool asks for tables, the site lists them. Read the list and press Create. You can also make tables yourself on the Data page: a name, the columns, and who shares the rows.
5. **Preview.** Open the preview. Only admins and managers see it. Preview has its own empty tables, so you can try anything.
6. **Make live.** Press Make live. The older version is kept; Roll back brings it back.
7. **Explain it.** Fill the info text (the i icon): what the tool is for, how to use it, who to ask.

## Who shares the rows
- **Private:** each person sees only his own rows.
- **Team:** everyone with the tool sees all rows. Contribute can add, Edit can change others' rows, Approve can delete.
- **Reference:** everyone reads; only managers change.

## Rules
- No real data, names, prices or passwords in the files. Data is typed into the tool and lives in the database.
- Nothing from outside the site in the files.
- You never need a database address, key or SQL.
