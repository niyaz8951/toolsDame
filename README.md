# DAME Platform

A master site for the company: IT controls sign-in, users and spaces; each department runs its own space and builds its own tools from the site, with no repo and no SQL.

This repo is a demonstration on GitHub Pages + Supabase. The design IT will run is in `docs/IT-GUIDE.md`.

Start with `docs/BEDROCK.md`, then `docs/DEMO-STACK.md`, then `docs/STATUS.md`.

No real data, key or password is ever stored in this repo.
