# IT admin

1. **Approvals.** New accounts wait here. Approve or refuse each one.
2. **Users.** Disable a leaver here. He loses everything at his next click.
3. **Spaces.** Create a space, give it an id (permanent, never reused) and name its first admin.
4. **Settings.** AI prompt: off, managers only, or all members. Quotas.
5. **Audit.** Who did what, when. Nothing here can be changed or deleted.

Site rules: `docs/BEDROCK.md`. Security rules: `docs/SECURITY.md`.
