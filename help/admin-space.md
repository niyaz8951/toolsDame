# Space admin

1. **Add a tool.** Press "Add a tool": name, short id (permanent), icon, colour, who may open it. For the icon pick one of the pictures, or type one or two letters.
2. **A tool is a tile.** Press its tile to open it. There, and only there: "Build and access", its name and look, its managers, switch off, delete. Press Done to close.
3. **Access.** Give or take a level per person: read, contribute, edit, approve.
4. **Admins.** Add or remove admins of this space. The last admin cannot be removed.
5. **Ideas.** Answer ideas posted on this space; set New, Planned, Done or Declined.

How to make a tool, step by step: `kit/tool-guide.md`. You never need SQL or a repo.
