# Tool admin

**Build this tool** starts with three choices and then shows one step at a time. The next step appears when this one is done; Back and Start again are always there.
- **Build a new page**: say what the tool should do; answer whether it saves data in the database; copy the starter kit to the approved AI (no real names, prices or customer data); paste the answer; read what the site found; upload.
- **I already have a page**: choose your HTML file; read what the site found; upload. If the site refuses it, one button hands it to the AI to be rebuilt.
- **Use a ready-made page**: no AI.

If the site finds something wrong, "Copy a fix request for the AI" writes the message for you. After the upload, open the preview, then press Make live twice. The older version is kept; Roll back brings it back.

**Data.** A tool keeps its rows in tables of this site. Make one by naming it, its columns and who shares the rows (team, private or reference); or press Create the tables when a checked page lists what it needs. Nobody types SQL. Columns can be added later; a table is deleted only after its name is typed, and its rows go with it. The preview has its own empty copy.

**Access.** Give or take a level per person: read, contribute, edit, approve.

**Managers** are named by the space admin.

The look, the top bar, sign-in and security come from the site. A tool brings only what it does. The building blocks are shown on the page "Building blocks".
